# Meus Estudos de Programação em C 🚀

Repositório dedicado ao armazenamento, revisão e fixação de exercícios práticos desenvolvidos durante meus estudos da linguagem C.

## 📝 Descrição do Projeto

Aprendendo e explorando C — exercícios de revisão e fixação com base nas atividades do **CodeHERs - Programação em C: do Código à Máquina**, oferecido gratuitamente pela ONG **Mente Binária**.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **Linguagem:** C
* **Editor de Código:** Visual Studio Code (VS Code)
* **Compilador:** GCC (via MSYS2 / UCRT64)
* **Controle de Versão:** Git & GitHub

## 📁 Como está organizadoS

Cada pasta neste repositório representa uma etapa ou assunto específico das aulas, contendo os arquivos de código-fonte (`.c`). Os arquivos executáveis (`.exe`) são ignorados automaticamente para manter o ambiente limpo.
